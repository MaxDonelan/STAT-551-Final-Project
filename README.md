# STAT-551-Final-Project
Code for the STAT 551 group final project.

# Project

### General objective: 
Develop and evaluate predictive models to determine which approach provides the strongest predictive performance for y (as continuous) and for a dichotomized version of y. 

##### Part 1. y is continuous, predictive models.

- Fit the standard multiple linear regression. Interpret results and assess if standard assumptions are violated.
- Fit and compare the predictive power of 5-6 models (e.g., OLS, regularized, GAM, tree, nnet)

##### Part 2. y is dichotomized as ybin = 1 if y >= 70, and ybin = 0 otherwise.

- Fit the standard binary logistic regression. Interpret results and assess if standard assumptions are violated.
- Fit and compare the predictive power of 5-6 models appropriate for categorical dependent variable.
